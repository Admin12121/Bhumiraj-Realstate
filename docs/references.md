# Reviewed official references

The architecture and package choices were checked against the current stable documentation before implementation. Review these sources again during dependency upgrades because framework behavior and integration contracts change.

- Bun package manager, workspaces, catalogs and Docker: https://bun.sh/docs/pm/workspaces and https://bun.sh/guides/ecosystem/docker
- Turborepo: https://turbo.build/repo/docs
- Next.js App Router, caching, self-hosting and Docker: https://nextjs.org/docs and https://nextjs.org/docs/app/guides/self-hosting
- React: https://react.dev/reference/react
- NestJS fundamentals, validation, guards, queues, WebSockets, adapters, security and testing: https://docs.nestjs.com
- Better Auth core, NestJS, database, admin, two-factor, social and passkey: https://www.better-auth.com/docs
- Prisma 7, PostgreSQL, driver adapters, migrations, raw queries and transactions: https://www.prisma.io/docs
- PostgreSQL indexes, locking and full-text search: https://www.postgresql.org/docs/current/
- PostGIS indexed distance/search: https://postgis.net/docs/
- Zod 4: https://zod.dev/
- TanStack Query queries, infinite queries, cancellation, hydration and mutations: https://tanstack.com/query/latest/docs/framework/react/overview
- Redis data types and Pub/Sub guarantees: https://redis.io/docs/latest/
- BullMQ workers, retries, concurrency and production guidance: https://docs.bullmq.io/
- Socket.IO server, Redis adapter, delivery guarantees and connection state recovery: https://socket.io/docs/v4/
- AWS S3 presigned upload and multipart APIs: https://docs.aws.amazon.com/AmazonS3/latest/userguide/PresignedUrlUploadObject.html
- Sharp metadata and resize behavior: https://sharp.pixelplumbing.com/
- ClamAV daemon INSTREAM protocol: https://docs.clamav.net/manual/Usage/Scanning.html
- MapLibre GL JS: https://maplibre.org/maplibre-gl-js/docs/
- shadcn/ui: https://ui.shadcn.com/docs
- Tailwind CSS: https://tailwindcss.com/docs
- React Hook Form: https://react-hook-form.com/get-started
- Playwright including WebAuthn/CDP support: https://playwright.dev/docs/intro
- Jest, Supertest, Testcontainers and k6: https://jestjs.io/docs/getting-started, https://github.com/ladjs/supertest, https://node.testcontainers.org/, https://grafana.com/docs/k6/latest/
- Nginx reverse proxy: https://nginx.org/en/docs/http/ngx_http_proxy_module.html
- MinIO S3 compatibility and CORS: https://min.io/docs/minio/linux/index.html
